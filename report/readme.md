# 报告目录

本目录用于正式技术文档、工程设计说明、验证记录和大模型协作记录。

- 正式技术文档由参赛者完成后放入本目录，可命名 technical_report.docx 或 technical_report.pdf。当前没有放入个人技术文档或空白模板。
- design_report.md 是根据现有工程和证据整理的设计说明，不代替参赛者填写的正式技术文档。
- project_status.md 和 known_issues.md 记录已验证范围与未解决问题；bf16_failed_cases.csv 保存失败明细。
- int8 与 verification 保存算子结果、工程重建和文件核验等技术证据。
- ai_collaboration.md 保留实际需求、回答选段和自我纠错；source_notes.md 记录来源与依赖。

图表位于 ../picture，测试输入与数值参考位于 ../data，实际捕获位于 ../sim。
