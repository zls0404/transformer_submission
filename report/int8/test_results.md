# INT8 测试结果与延时

测试时钟为 100 MHz。以下为首个输入采样到首个/最后一个输出采样的时间；矩阵乘法包含本测试的权重和特征流加载，不包含 PS 和 DMA。

|对象|通过情况|首结果 / ns|全部结果 / ns|说明|
|---|---|---|---|---|
|baseline Softmax|100/100 分帧检查；未设数值验收阈值|730～6490|1040～9680|各输入尺寸的明细见 CSV|
|ISCAS 串行|94/100 定点一致|730～6490|1040～9680|各输入尺寸的明细见 CSV|
|ISCAS 并行|100/100 定点一致|480～4800|790～7990|各输入尺寸的明细见 CSV|
|标量 GELU|15/15 定点一致|70～70|2620～2620|各输入尺寸的明细见 CSV|
|整数矩阵乘法|16/16 定点一致|1000～16000|1030～16230|各输入尺寸的明细见 CSV|

Softmax：N=32～320。标量 GELU：每组 256 个连续输入，首结果 70 ns，全部结果 2620 ns。SIMD GELU 背压测试单独发现 4 次数据保持违例，不能把标量数值一致解释为 AXI-Stream 封装通过。

baseline Softmax 的 MAE（相对浮点输入的理想 Softmax）为 0.003696663，格式参考 Q 的 MAE 为 0.002256341，R 与格式参考 Q 的 MAE 为 0.003440791。误差含输入/输出量化和硬件近似，需结合网络精度确定验收阈值。

ISCAS 串行第 3、5、25、45、65、85 组与定点参考不一致，涉及全负输入，差异保留。并行候选在此输入集上逐元素一致；它不在当前默认综合路径中。
