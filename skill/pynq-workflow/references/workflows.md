# 可复用工作流模板

将方括号内容替换成实际材料。模板用于组织判断和调用工具，不代替接口规格。实测效果以 validation 中的试用记录为准，未试用的模板不写成稳定提升了通过率。

## 从 IP 整理主机接口

```text
使用 pynq-workflow。目标板卡/器件为[型号]，PYNQ版本为[版本或未知]。
已有材料：[bit/hwh、RTL或HLS、寄存器说明、数据格式、输入输出规格]。
当前任务范围：[只离线检查/建立工程/上板执行]。

先核对产物和实际综合参数，整理接口契约：IP层次名、寄存器偏移及副作用、
输入输出编码、元素数和字节数、启动顺序、TLAST/TKEEP、完成条件、超时。
用check验证可自动检查的部分；算法缓存和字段位宽另列依据。
缺少关键协议时说明具体缺失项，不猜地址、不自动改RTL。
按任务范围完成调用与原始证据，区分静态通过和真实运行结果。
```

## DMA 或首帧异常定位

```text
使用 pynq-workflow。现象：[卡住/短帧/未知值/首帧异常]。
输入与环境：[规格、版本、时钟、阶段顺序]。
证据：[契约、HWH参数、原始状态、仿真/板端记录]。

先判断是否仍有在途DMA，保存状态并保持buffer所有权。
核对字节数、地址范围、DRE、TLAST、valid/ready和复位。
按证据提出一个最小复测，区分已知事实、支持的推断和未知根因。
不得将模拟结果写成板测，也不因卡住直接增加超时、释放buffer或重启板卡。
```

## 数值与性能报告

```text
使用 pynq-workflow。提供F浮点参考、Q量化参考、R真实捕获和计时原始样本。
数学定义：[公式/近似]；Q模型类型：[逐位/格式目标]；编码：[位宽及缩放]；
验收阈值：[测试前声明的atol/rtol及近零规则]。

先核对元素数、索引和非有限值，再分别比较Q-F、R-F、R-Q。
保留失败和全部样本，报告MAE/RMSE/max_abs/relative_L2及未定义项。
若画图，仅使用真实原值，局部放大不移动曲线，重合如实标注。
计时写明起终点、上传/DMA范围和预热规则，报告分位数与最大值。
静态资源/时序结果另列，不与数学或板端功能结论混用。
```

## 换题目/换板卡

```text
使用 pynq-workflow，将[原应用]迁移到[新应用/板卡]。
保留通用工具，比较接口契约中必须改变的部分；不要复用原板比特流或PS预设。
新板的器件、DDR/MIO、时钟和约束需重新确认并构建。
先用最小回环验证软件/硬件接口，再验证目标应用和故障恢复。
列出保留项、修改项、实际运行证据和仍待物理验证的部分。
```

独立回环硬件模板见 assets/create_loopback.tcl：仅支持 Zynq-7000 PS7，需要该板实际预设。它作为第二应用的构建案例，不覆盖 ZynqMP 硬件生成；通用软件检查不受此模板器件边界限制。
